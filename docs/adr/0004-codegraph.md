# ADR 0004 — CodeGraph как структурный индекс

## Контекст

Агенту нужно быстро отвечать на вопросы о вызовах и зависимостях в
разросшемся пакете. Grep/read даёт фрагменты и требует много вызовов.
CodeGraph уже используется в проекте (`.codegraph/`).

## Решение

- Держать `.codegraph/` локально, не коммитить базу.
- `codegraph.json` исключает build/cache/temp.
- В `AGENTS.md` и `docs/CODEGRAPH.md` зафиксировано: для структурных вопросов
  сначала `codegraph_explore`, затем CLI-эквиваленты.
- `docs/codegraph-system-prompt.md` — готовый промпт для агента.
- После переезда файлов — `codegraph sync .`.

## Последствия

- Меньше tool-calls и токенов на исследование.
- Индекс может отставать на несколько секунд; stale banner нужно уважать.
- CodeGraph не является рантайм-зависимостью приложения; без него сборка и
  тесты работают.
- При обновлении CodeGraph проверить `codegraph.json` и промпт.
