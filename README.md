# NordScribe 🎙️🧠

**NordScribe** — это мощное десктопное приложение для полностью локальной и конфиденциальной транскрибации аудио в текст с последующим интеллектуальным анализом с помощью ИИ.

## ✨ Особенности

- 🔒 **Полная конфиденциальность**: Все вычисления выполняются локально на вашем устройстве. Никакие данные не отправляются в облако.
- 🎙️ **Транскрибация Whisper**: Высококачественное распознавание речи благодаря модели OpenAI Whisper.
- 🎤 **Запись с микрофона**: Записывайте речь напрямую в приложении.
- 🧠 **AI Анализ**: Интеграция с локальными LLM через Ollama для суммаризации, перевода и анализа текста.
- 🎨 **Современный UI**: Приятный интерфейс на базе `customtkinter` с поддержкой темной темы.
- ⚡ **Многопоточность**: Интерфейс остается отзывчивым даже во время тяжелых вычислений.

## 🛠️ Требования

- Python 3.8+
- Операционная система: Windows 10/11, Linux, macOS
- **FFmpeg**: Обязателен для работы Whisper.
  - *Windows*: Скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html), распакуйте и добавьте папку `bin` в переменную среды PATH.
  - *Linux*: `sudo apt install ffmpeg` или `sudo dnf install ffmpeg`.
  - *macOS*: `brew install ffmpeg`.
- **Ollama**: Установите с [ollama.com](https://ollama.com) и скачайте легкую модель (например, `qwen2.5:1.5b` или `llama3.2`).
  ```bash
  ollama pull qwen2.5:1.5b
  ```

## 🚀 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/nordscribe.git
   cd nordscribe
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## ▶️ Запуск

```bash
python nordscribe_main.py
```

## 📖 Как использовать

1. **Транскрибация файла**: Нажмите "📁 Загрузить аудиофайл" и выберите аудио (mp3, wav, m4a и др.).
2. **Запись с микрофона**: Нажмите красную кнопку "🎤 Записать с микрофона", говорите, затем нажмите "⏹ Остановить запись".
3. **AI Анализ**: Введите запрос в правое поле (например, "Сделай краткое содержание" или "Переведи на английский") и нажмите "✨ Анализировать текст".
